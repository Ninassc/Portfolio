# 🌟 Portfolio

Este repositório apresenta um portfólio desenvolvido para exibir projetos de desenvolvimento de forma clara, organizada e visualmente agradável.  
O objetivo é reunir trabalhos, estudos e experimentos em um único espaço, facilitando a navegação e oferecendo uma visão geral das habilidades aplicadas em cada projeto.

## 📌 Conteúdo do Portfólio
• Projetos de desenvolvimento web  
• Exercícios e aplicações práticas de programação  
• Interfaces criadas em HTML, CSS, JavaScript e React  

## 🛠 Tecnologias utilizadas
• HTML  
• CSS  
• JavaScript   

## 🎯 Objetivo do projeto
Exibir de forma simples e intuitiva os trabalhos desenvolvidos, permitindo visualizar a evolução técnica e criativa ao longo do tempo.
